The Four Modes

Four ways to build.
One desktop app.

Every PacketADE workflow falls into one of four modes — from fully autonomous Missions down to a single focused chat. Pick the mode for the work in front of you. Mix them freely.

Mode 01 · Full Autonomous

Flight Deck

Write a spec. A Sonnet 4.6 planner decomposes it into milestones and tasks, executors run end-to-end, and you only step in to approve gates. Status, blockers, and costs roll up automatically.

When: Large multi-step work you want to delegate — “ship the feature” and walk away.

Mode 02 · Semi-Autonomous

Workspace

Tile PTY-backed CLI agents — Claude Code, Codex, Gemini, OpenCode, PacketCode — in worktrees. Give each one a task, supervise mid-stream, reply, switch, branch, and steer them all in parallel.

When: Hands-on work where you orchestrate multiple agents and want a Bypass-perms throttle within reach.

Mode 03 · Single-Thread Chat

Agents

One conversation, one API agent — Claude OAuth subscription, OpenAI API, MiniMax, OpenRouter, or local Ollama. Structured chat with tool diffs, slash commands, @-file mentions, and voice input.

When: Focused threads, exploratory questions, anything where one chat is the right shape.

Mode 04 · AI-Structured Intake

Issues

Paste a spec, doc, or PRD. AI breaks it into discrete tickets. One click “Send to Workspace” spawns a Claude pane in a worktree with the ticket as the opening turn. Commits with Fixes #N auto-close.

When: You want AI to structure the work but you (or a supervised agent) drive the coding.

Mix and match. Hand a Mission off to Workspace. Promote a chat to an Issue. Every mode shares memory, costs, and providers.

Remote Agents are the next big bet

PWA first, Packet account sign-in, Packet Cloud relay, and desktop-owned execution. Use PacketADE Agents from your phone without sending provider secrets or tool access to the cloud.

Phone control, desktop ownership

The PWA can list providers, models, profiles, workspaces, and conversations; start or continue API-agent chats; stream api-agent:* events; and approve permission or edit prompts. Files, shells, MCP servers, provider secrets, and execution stay on the PacketADE desktop.

Sign in, then trust a host

Packet account sign-in is the primary flow. A desktop must still approve and trust each device before it can control conversations.

Relay, not cloud agent

Packet Cloud carries encrypted frames and push notifications. It does not call OpenAI, Anthropic, Ollama, shells, or MCP tools.

Push only for attention

Foreground work streams over WebSocket. Web Push is reserved for approval requests, pending edits, errors, and done summaries.

Cross-cutting capabilities

Eight features that compose across every mode — from Missions to a single chat.

BYOK across eight provider rows

Anthropic subscription + API, OpenAI ChatGPT + API + Agents SDK, MiniMax, OpenRouter, and local Ollama. Streaming tool use, cache-aware token metrics, OAuth refresh handled for you.

Agent Profiles

Five built-in personalities — Auto, Speed Runner, Thorough Reviewer, Security Auditor, Refactor Pro — plus custom profiles. System prompt, tool allowlist, and default model in one keystroke.

Code Quality with AutoFix & AI Explain

Live-streaming lint, typecheck, test, and audit runner. ESLint --fix, Prettier --write, cargo fix, npm audit fix — one click each. Per-error AI Explain, one-shot "Fix in Workspace" that spins up a Claude pane in a worktree, and a cached AI summary at the bottom of every run.

GitHub, deeply wired

Merge / squash / rebase, draft toggle, CI status pills, AI PR descriptions, streaming pre-flight code review, "Catch me up" repo digests, bulk issue triage. Plan flights, branch from issues, or hand off to Claude in one click.

Worktree-bound commits

Issues spawn a Claude pane inside a Git worktree with a prepare-commit-msg hook that auto-appends Fixes #N and Run-By: PacketADE trailers. Commits matching the trailer auto-close the linked Issue.

Cross-provider cost dashboard

Unified spend across Claude CLI, Codex, and every API row. Cache-aware token metrics, per-model breakdowns, per-flight totals, and a live spend chip in the toolbar.

Deploy pipeline

Configure environments, trigger deploys, stream live terminal output. Run history with status, env vars, and per-run logs — reachable from the global + New menu.

Voice-to-text, OS-wide

Native Whisper dictation with waveform, history search, sentiment trend, and WPM analytics. Push-to-talk anywhere with Ctrl+Shift+V — transcripts land at the cursor of your last-focused input, or in the clipboard if focus is gone.

Modes compose. Memory persists. Costs total up.

The four modes share workspace state, memory, providers, and a single spend ledger — so handoffs are zero-friction.

1

Structure intake

Paste a PRD into Issues. AI breaks it into tickets with labels, acceptance criteria, and a suggested epic. Drop each into Backlog or Up Next.

2

Choose the right autonomy

Big multi-step features → Flight Deck. Hands-on parallel work → Workspace with worktree-bound panes. Focused threads → a single Agents chat.

3

Ship and roll up

Fixes #N trailers auto-close Issues. GitHub merges with AI-drafted PRs. Deploy from + New. The spend chip totals every provider on the way out.
