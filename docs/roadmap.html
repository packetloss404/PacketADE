v0.7.0 2026-05-15

Mission Planner v1 — autonomous spec-to-ship

The headline feature. An AI mission planner that owns a spec end-to-end — one Sonnet 4.6 session per mission, callable tools, journal, safety rails, context compaction.

Spec-mode chat → autonomous decomposition into 2–4 milestones and 4–10 tasks, each spawned in its own worktree
Self-driving lifecycle — reacts to task completions, replans on retryable errors, escalates via the async approval gate
Per-mode tool-call caps, rate-limit auto-resume, kill switch, watchdog, cold-start enforcement
Append-only mission journal + planner-vs-executor cost split with cumulative-token chip for OAuth
Context compaction at 150K input tokens so multi-day missions don't hit the context wall

v0.8.0 2026-05-15

GitHub pane overhaul + Memory inline surfaces

The GitHub pane went from read-only viewer to real daily-loop tool. Memory surfaces moved out of their dedicated tab and into the places you actually work.

PR lifecycle actions: merge / squash / rebase / close / reopen / draft toggle, live CI status pills, Checks tab
AI features: PR description generator, pre-flight code review with Blocking/Asks/Nits, "Catch me up" repo digest, bulk issue triage
5 issue CTAs wired end-to-end: Plan flight, Branch from issue, Hand off to Claude, Draft patch, Save as memory
Mission attempts auto-publish as draft PRs; workspace auto-binds to origin; Run-By: auto-trailers on agent commits
Memory: context-preview chevron, MissionsView memory chip, "Recent learnings" feed, project-scoped patterns, pin button wired

v0.8.5 2026-05-16

Issues pane rebuild — spec import & close-loop

Issues became the fourth user-facing mode: AI-structured intake from any spec or PRD, with a complete commit-to-close loop through Workspace.

Spec import — paste a PRD, get back structured Issue drafts with title, body, labels, acceptance criteria, suggested epic
Send to Workspace — provisions an issue-bound worktree, installs prepare-commit-msg hook, opens Claude pane with the issue seeded
Auto-Done on Fixes #N trailer — commits that close a ticket flip its column and append an audit comment
New 5-column board: Backlog / Up Next / In Progress / In Review / Done; multi-select filter chips; inline comment composer
Full IssueDetail modal: markdown body, criteria checklist, dependencies, linked workspace pill, status grid, comment thread

Queued · Tier 02

What's next on the bench

Curated from backlog.md. Priority pills follow our internal convention: P1 is a real bug or major user-facing gap, P2 is correctness or UX worth shipping this quarter, P3 is opportunistic cleanup. Dates aren't promises — these ship when they're ready.

Remote Agents

current flagship · PWA + Packet Cloud relay
P1
Packet Cloud relay MVP — Worker/Durable Object relay, desktop connector, host/session routing, reconnect semantics, and relay observability.
P1
Account sign-in + device trust — Packet account auth, desktop-side approval, revocation, and audit trail. QR is optional later, not the primary flow.
P1
PWA conversation shell — conversation list, chat stream, provider/model/profile picker, approval sheets, and reconnect/offline states.
P1
Secure remote command envelope — narrow API-agent commands only; no generic remote Tauri bridge and no cloud-side provider secrets.

SSH & remote workspaces

5 items · biggest open gap
P1
Sidecar-over-SSH (Phase 4.1) — swap local node for ssh-piped node so Claude OAuth + Codex OAuth work against remote codebases. The biggest user-visible gap after v0.6.0.
P1
Remote-workspace consumer sweep — type-level fix or guard every workspace.projectPath consumer for the local-or-remote union.
P2
MCP servers over SSH (Phase 4.2) — build_mcp_config_for_sidecar currently hardcodes local paths, so remote workspaces lose MCP tools entirely.
P2
Remote git dashboard write commands — today remote workspaces can read git status but not commit/push/pull. Half-implemented is worse than no feature.
P2
Password-auth fixes — migration silently downgrades password-auth users to "agent"; ssh_check_remote_path doesn't pull the saved keyring password.

Mission Planner v1.1

5 items · deepens v0.7
P2
Helper planner escalation — primary planner calls spawn_helper_planner(scope, reason) for heavy decomposition. Cap: 1 successful spawn per mission. Stub in v1 returns "deferred to v1.1".
P3
Back-port milestone-gating to async path — pause-between-milestones and file-collision detection from the PTY orchestrator don't exist on the planner's async path yet.
P3
Predictive quota awareness — today's safety is reactive: catch RateLimitError, pause, auto-resume. Switch to predictive once Anthropic SDK exposes anthropic-ratelimit-* headers.
P3
Crash-resilient planner sessions — persist lastResumeToken so cold-start can rehydrate active missions instead of flipping them to Paused.
P3
Incremental journal fetch + size cap — chatty turns currently trigger 5-20 full-file reads. Add read_journal_after(last_entry_id) + max-bytes safeguard.

Memory v0.9+

4 items · from v0.8 deferrals
P2
Embedding / RAG over memory — today's retrieval is keyword + recency. An embedding layer (sqlite-vss or LanceDB) unlocks semantic context injection.
P2
Pre-execution memory brief — when a Mission attempt launches, compose a short "what we know about this codebase" brief and inject it as the first user turn.
P3
Recurring-error detector — pattern-extraction pipeline watches for repeated failure modes and surfaces a "this looks familiar" hint on next launch.
P3
"Ask your project" chat tab — chat surface querying memory directly. Trivial once RAG lands; keyword fallback ships first.

GitHub v0.9+

4 items · from v0.8 deferrals
P2
Authored PR line comments — v0.8 shipped read-only thread viewing. New thread composition needs the in-diff composer UI + two backend command pairs.
P2
Notifications inbox — GET /notifications integration with a dedicated tab, unread badge, mark-as-read, link-back to source.
P3
Releases / gists / Actions runs view — out of scope for v0.8. Worth picking up if the GitHub pane grows into a fuller client.
P3
Windows hook shim — v0.8's prepare-commit-msg hook is POSIX shell. Add prepare-commit-msg.cmd for vanilla Windows OpenSSH targets.

Platform & distribution

4 items · ops, not features
P2
Auto-updater (Tauri v2) — signing keypair + signed latest.json + UI prompt. Currently PacketADE is manual-install. Runbook lives in dev/updater-setup.md.
P2
macOS code signing + notarization — replaces today's xattr -cr Gatekeeper workaround. Requires Apple Developer ID enrollment.
P2
Windows Authenticode signing — kills the SmartScreen warning on first run. EV cert is the fast path.
P3
Snap / Flatpak packaging — broadens Linux reach beyond today's AppImage + DEB.

Performance & polish

3 items · visible wins
P3
Cost dashboard planner / executor split — post-E8, plannerCost + derived executorCost are on every Mission. Surface the split in the dashboard view.
P3
Cost-update event verbosity — turn-summary events currently fire a full flightStore.hydrateFromBackend(). Patch just the affected flight instead.
P3
Compaction summary in wake messages — planner currently relies on priming context alone post-compaction. Include the latest summary verbatim in wakes until next compaction.

This isn't the whole backlog.

The full backlog.md has 100+ items including P3 cleanups, code hygiene, and minor polish work. The list above is curated to give you a sense of direction. If you want to pick something up, open an issue referencing the backlog item — contributions are welcome.
