02 Benefits — why / why not

For each backlog item: the case for doing it, the case against, and a verdict. Cards keyed by category (SSH & remote workspaces · Platform & distribution · Product tracks).

SSH & remote workspaces 20 items

Remote-workspace consumer sweep

P1
Whyworkspace.projectPath holds either a local or remote path; latent bug class. Scout in IdeaCard.tsx:26 already relies on upstream gating only. Why notTyping the union right means touching many consumers; risk of regressing local flows.
Worth doing now — the underlying type confusion is a footgun for every new feature that touches a workspace.

Sidecar-over-SSH (Phase 4.1)

P1
WhyUnlocks Anthropic Subscription + OpenAI ChatGPT providers against remote codebases — the biggest user-visible gap after v0.6.0. Why notRequires bundling sidecar + Node onto the remote (parallel to CLI auto-install). Larger than a one-week task.
High leverage — currently hard-blocked by the Phase 1.1 error gate, so the gate is "free" to remove once this ships.

"Will be created" copy fix

P2
WhyUser-visible truth bug — the modal promises something the app doesn't deliver. Why notEither ship the mkdir -p or revise copy — picking is a 5-minute call.
Cheap; fix the copy in the same PR as the mkdir -p if we do it.

ssh_check_remote_path uses keyring password

P2
WhyPassword-auth users can't validate remote paths in the wizard — silent failure mode. Why notAdds one keyring lookup; trivial.
Do it — keyring read is small and unblocks a documented auth method.

Password-auth migration silently downgrades

P2
WhyExisting users with keyring-stored SSH passwords lose that method on upgrade and won't know why connections fail. Why notTouches the migration that already shipped — risk of re-introducing migration bugs.
Ship a one-time toast + check getSshPasswordExists during migration.

Read-only remote git dashboard

P2
WhyToday remote workspaces show git status but can't commit/push/pull — half-implemented feature is worse than no feature. Why not4 new Tauri commands with validation and shell-escape; not trivial but the harness from Phase 3.3 is reusable.
Land it — completes a flagship v0.6.0 surface.

MCP servers over SSH (Phase 4.2)

P2
WhyWithout it, remote workspaces lose MCP — a big chunk of the agent toolset evaporates. Why notTouches the sidecar protocol seam; coordinate with Phase 4.1.
Do after 4.1 lands — same code paths benefit.

Consolidate CloneServerConfigDto + GitServerConfigDto

P3
WhyByte-identical structs in two files — drift will happen. Why notPure cleanup, no user-visible win.
Do opportunistically when next touching either file.

clone_repo_remote needs a frontend caller

P3
WhyBackend command + binding exist with no UI — dead code or undelivered feature. Why notSurfacing a UI is more than P3 effort; removing is the cheaper P3.
Either surface it in a "Clone to remote workspace" wizard step, or remove the binding. Decide before next refactor.

Sidecar-providers list drift

P3
WhyHand-mirrored lists in TS and Rust — silent drift breaks the Phase 1.1 sidecar guard. Why notExisting list is small (2 entries); breakage is loud not silent.
Wait until adding a 3rd sidecar provider; do the codegen then.

Dead Tauri commands

P3
WhyFour registered commands with no callers — attack surface for no benefit. Why notSome may be repurposable for the keyring-password fix above.
Either reuse for the password-auth probe, or strip in one cleanup PR.

Rename target_id → server_id

P3
WhyField name preserved for back-compat; long-term clarity matters. Why notBreaks any persisted state from older versions if not migrated.
Schedule after 1–2 minor versions ship; pair with a schema-version migration.

resumeApiConversation partial live-config lookup

P3
WhyHost/user/remotePath from persisted state means a renamed server resumes wrong. Why notFail-fast on creds is arguably the correct mode; users notice instantly.
Document, don't fix, until a user reports it.

Sentinel rename PACKETCODE_*

P3
WhyBrand consistency in two server-internal constants. Why notPure cosmetic — neither user nor logs see it.
Fold into the next pty.rs / tool_runtime_ssh.rs touch.

cancel_flight_attempt fingerprint asymmetry

P3
WhyCodepath asymmetry — FE carries fingerprint, BE doesn't. Why notCleanup is deferred to FE; works correctly today.
Cosmetic; align when refactoring flight cancel paths.

Unit test for sshTargetMigration.ts

P3
WhyIdempotency + ID preservation + dual-legacy-key cleanup deserve direct coverage. Why notMigration ran fine in v0.6.0; live signal is good.
Worth ~30 minutes for a regression test before any future migration touches the path.

Heredoc terminator predictability

P3
WhyPredictable terminator is grep-able; minor hygiene. Why notExisting collision check catches the failure case.
Random hex suffix is a 5-line change; do it for hygiene.

keyPath argv hygiene

P3
WhyArgv-level injection is safe by construction, but logged paths with shell metachars could surprise. Why notNo live exploit path — defensive only.
Reject obviously hostile paths at ServerFormModal save; one regex.

SFTP / port-forward / 2 MB file cap (Phase 4.3)

P3
WhyHeredoc-piped file ops cap at 2 MB — blocks legitimate large-file workflows. Why notSFTP adds a second transport layer; large change for a corner-case use.
Defer until a real user hits the cap. Track usage telemetry first.

Windows-OpenSSH remote hosts

P3
WhyPOSIX [ -e ] / git -C assumptions break on Windows-OpenSSH targets. Why notVery few users target Windows as a remote dev host.
Document the limitation; revisit only if requested.

Platform & distribution 5 items

Auto-updater (full Tauri v2 wiring)

P2
WhyManual-install is friction for a daily dev tool. Updater unlocks rapid iteration without retraining users to download installers. Why notSigning keypair, hosted manifest, release pipeline — three concurrent prerequisites. Runbook exists in dev/updater-setup.md.
Highest-leverage P2; pair with macOS + Windows signing for a coherent "trust the binary" milestone.

macOS code signing + notarization

P2
WhyUnsigned .app hits Gatekeeper. Notarization is required for distribution-grade DMGs. Why notApple Developer ID enrollment + notarytool setup are ops tasks; cost ~$99/yr.
Required for shipping macOS. Bundle with the auto-updater milestone.

Windows Authenticode signing

P2
WhySmartScreen warning on first run hurts trust signal. Why notEV cert is $200–$400/yr; standard cert needs reputation accrual.
Required for shipping Windows publicly. Same milestone as macOS signing.

Snap / Flatpak packaging for Linux

P3
WhyBroadens distro reach beyond AppImage + DEB. Why notTwo more packaging targets, each with their own quirks.
Only after the AppImage user base proves Linux is a real channel.

Cross-compile Windows from macOS / Linux

P3
WhyLets CI matrix collapse to one runner. Why notOfficially unsupported by the current Tauri toolchain.
Won't-fix until release matrix demands it. Use native runners instead.

Product tracks 4 items

Cost dashboard alerts

P2
WhyCost anxiety is the #1 reason users don't leave agents running unattended. Alerts unblock confident automation. Why notNotification surface decisions (modal? toast? OS?) need design.
Ship the simplest threshold-based alert first; iterate UX.

Swarm orchestration Phase 4 escalation

P2
WhyAuto-reassignment of stuck flight attempts closes the resilience gap for autonomous flights. Why notHeuristics for "stuck" are non-trivial; false escalations are worse than none.
Build on top of bounded-concurrency / orchestrator backpressure; do them together.

PacketADE MCP provider transport

P2
WhyPhase 1 frontend exists; transport layer makes the MCP-provider story actually usable. Why notPlan doc is comprehensive but several months old; verify against current code.
Do after the MCP-over-SSH (Phase 4.2) work — same surfaces.

Workspace UX gaps

P3
WhyGit review-packet ties + command-palette integration round out the v0.5 workspace work. Why notTwo unrelated half-features; better split into separate PRs.
Pull when adjacent code is open; not worth a dedicated sprint.

03 30 ideas after the backlog ships

Curated from a 60-idea brainstorm by two parallel agents (product/UX angle + engineering excellence angle). Tiered by category; effort labels are S (≤ 1 wk) · M (1–2 wk) · L (2–4 wk) · XL (> 1 mo).

01

Time-travel "rewind to here"

Click any chat turn to restore worktree + memory + plan state to that exact point and branch a new attempt. Undoes the "agent went off the rails" panic without git reset gymnastics.

Extend agentTaskStore with checkpoint indexes · new rewind_conversation Tauri command snapshotting .pkt-worktrees/<convId> · RewindMenu in AgentChatPane.
Killer featureXL
02

Plan-then-Race mode

Write one goal; dispatch the same plan to Claude + Codex + Gemini in parallel worktrees; a Reviewer agent picks the winning diff or merges hunks across attempts. Direct extension of the existing Plan→Codex handoff.

New RaceController in orchestration.rs · third launch mode in NewFlightModal · reuses worktree-per-conversation from v0.5.
Killer featureL
03

Mission DAG canvas

Visual node-graph of mission → phases → tasks → attempts with streaming agent positions, blocked edges, and approval gates rendered as glowing seams. Replaces master-detail lists with a spatial map.

New MissionDagCanvas.tsx in src/components/missions/ · fed by flightStore + flight_attempts.rs · React Flow or custom SVG.
Killer featureL
04

Agent screencast replay

Every conversation auto-records a deterministic replay (tool calls + diffs + plan blocks, not raw stdin) playable at 4× like a debugger trace. Scrubable, exportable as a shareable .pktcast file.

Persist session-registry events in SQLite · new ReplayPane.tsx · export through history.rs.
Killer featureM
05

Goal-bound contracts (Definition of Done)

Each /goal gains a machine-checkable contract: passing test command, file-path checklist, or LLM-judged predicate. PlanPanel footer shows green/amber/red; agents auto-stop when contract passes.

Extends goalStore + MilestonesPanel · new goal.contract field · runner in orchestration.rs.
Killer featureM
06

Pair Mode — dual-agent chat

Split AgentChatPane vertically with two agents on the same goal; user types once, both stream, diffs/plans cross-link, accept-the-better-hunk merges into the active worktree. Productizes the manual "two terminals" workflow.

New PairChatPane.tsx wrapping two AgentChatPanes · agentTaskStore adds pairId linking two conversations.
Killer featureM
07

Live PR co-review

Attach a flight to a GitHub PR URL; agent reviews the diff in a ReviewPane showing inline AI comments, severity dots, and "Apply suggestion" → commits to a fixup branch via the existing PR-creation flow.

New PrReviewPane · backend gh_fetch_pr_diff · reuses /review subagent from v0.5.
Killer featureL
08

Conversation forking + merge

Right-click any turn → "Fork from here" spawns a sibling conversation that shares history but diverges. "Merge into parent" replays a summarized result back. Solves "I want to try a tangent without losing my place."

agentTaskStore adds parentId + forkedFromTurnId · UI in turn context menu and AgentSidebar.
Killer featureM
09

Acceptance-criteria-driven test gen

From an Issue's acceptance criteria, "Generate test stubs" creates failing tests in the worktree before the agent starts. Mission closes when tests go green. Closes the loop between issue tracker and agent.

issueStore → new generate_tests_from_criteria command in code_quality.rs · hooked from issue detail modal.
Killer featureM
10

Memory layer "ask the past"

Semantic search over Session History + Learned Patterns + Memories with citation back to the originating conversation. Exposed as /recall <query> slash command and as a MemoryRecallPane.

New embeddings index (sqlite-vec) on memoryStore · /recall in slash-command registry · pane in tabbed right rail.
Killer featureL
11

Universal command palette

Cmd-K opens a Raycast-style palette unifying every slash command, every saved prompt template, every MCP tool, every project-defined skill. Power-user retention bait — once you live in Cmd-K you don't switch.

New CommandPaletteModal · pulls from agentTaskStore.slashCommands, promptLibraryStore, mcpStore, new skillStore.
Power-userM
12

PacketADE Skills (project-scoped macros)

.packetade/skills/<name>.md is a Markdown skill (prompt + allowed tools + optional script). Auto-discovered, surfaced in palette, shareable in repo, callable from agent as Skill(name).

New skill.rs watching project root · integrates with core::agents_md cascading resolver · SkillsCard in Settings.
Power-userL
13

Workspace recipes (one-line dev envs)

A .packetade/workspace.yaml declaring panes, agents, profiles, env vars, kickoff prompts. Open the repo → pane layout, agents, and starter goals reconstitute in two seconds. Devcontainer for agent IDEs.

New recipe.rs + loader in workspaceStore.createWorkspace · "Use repo recipe" toggle in WorkspaceCreationModal.
Power-userM
14

Smart approval policies as code

~/.packetade/policies.toml with rules like allow when tool == Write && path.startsWith("test/") or require_human when diff.lines > 200. Versionable, reviewable, team-shareable.

New core/policy.rs evaluating against permission_request · UI in Settings → Policies · pairs with profiles' allowedTools.
Power-userM
15

Project Briefcase export

One-click bundle of AGENTS.md + policies + skills + saved prompts + MCP config + agent profiles into a signed .pktbrief file. Team members run "Import briefcase" and their environment matches.

New briefcase.rs packing from existing stores · UI in Settings → Team.
Power-userM
16

Plugin SDK v0 — declarative manifest

Define a plugin manifest: declarative views, declarative toolbar buttons, declarative slash commands wired to MCP tools. Ship a marketplace registry. Defer arbitrary-JS plugins to v1 (sandboxing is hard).

Generalize src/modules/registry.ts to load from disk · new core/plugin_manifest.rs · existing module registry becomes the first consumer.
PlatformXL
17

MCP Marketplace pane

First-party curated registry inside the app: search, one-click install with scope picker, sandboxed credential prompts, rating + last-verified-with-PacketADE badge. Owns MCP discovery before competitors do.

New McpMarketplaceView.tsx · builds on mcpStore + mcp.rs · static JSON manifest hosted at marketplace.packetade.dev.
PlatformM
18

TodayView — mission inbox & standup

First-tab default on app open: missions paused awaiting approval, attempts that finished overnight (diff stat + cost + tests passed Y/N), new GitHub PR comments on linked PRs. Brings users back daily.

New TodayView.tsx as the first-tab default · reads flightStore, analyticsStore, gh.rs.
PlatformM
19

Spec-to-suite generator

Paste a PRD or a Figma frame URL, get back: issues with acceptance criteria, draft test stubs, file scaffolds, and a Mission DAG linking them — all editable before commit. PRD-to-PR-in-progress pipeline.

Extends spec.rs + Spec2Tick · pipes into idea 09 (tests) + 03 (DAG canvas).
PlatformL
20

Scripting hooks for flight lifecycle

Extend core/hooks.rs with flight.created, flight.task.completed, flight.attempt.failed, agent.permission.requested. Allow per-event shell-script hooks in ~/.packetade/hooks/.

src-tauri/src/core/hooks.rs · commands/flight_attempts.rs emit sites.
PlatformM
21

Schema versioning + forward-compat reader

Every blob in core/storage.rs gets { "schema": N, "data": ... } with a migration registry. Prevents the next host_fingerprint-style silent-deserialization panic on old installs.

core/storage.rs + new core/schema_versions.rs with MIGRATIONS array.
ReliabilityM
22

Crash-safe atomic writes for all state

Replace direct fs::write with write-temp-then-rename + fsync in storage.rs. A power loss mid-save_workspaces_slice currently truncates the slice to zero bytes, wiping every workspace.

src-tauri/src/core/storage.rs write helpers.
ReliabilityS
23

DTO round-trip contract tests

For every Zustand store with a localStorage slice: fuzz a record, persist, hydrate, deep-equal assert. The serverId/remoteProjectPath silent-drop bug was systemic — this kills the bug class.

src/stores/__tests__/dtoRoundtrip.test.ts + helper in lib/tauri.ts · wired into vitest run.
ReliabilityM
24

Integration test harness — scripted PTY + sidecar

Headless Tauri (MockRuntime) boots, spawns the real sidecar against a stub echo provider, drives 20 message turns, asserts no leaked tasks/files/handles. Would have caught both v0.5.0 standalone-exe regressions.

New src-tauri/tests/it_sidecar_smoke.rs · reuses agent-sidecar/test/registry-smoke.mjs stub.
ReliabilityL
25

Flight orchestrator backpressure + bounded queue

tokio::sync::Semaphore per flight + a global cap on concurrent attempts. Prevents a 100-task flight from launching 100 sidecar sessions, ballooning RAM and tripping rate limits.

src-tauri/src/core/orchestrator.rs · prerequisite for the swarm Phase 4 escalation work in the current backlog.
ReliabilityM
26

W3C traceparent across FE → Rust → sidecar

Every Tauri invoke gets a traceparent; Rust logs it via tracing::Span; sidecar protocol gains a trace envelope. Debug a stuck api-agent:done with one rg <id> across all three layers.

New src/lib/trace.ts wrapping invoke · SidecarRequest gains trace_id (protocol v5) · Span::record in lib.rs.
Perf / SecM
27

Sidecar warm-start daemon

Persist the sidecar process across PacketADE restarts via a small packetade-sidecard socket (named pipe on Windows, unix socket elsewhere). Kills the ~600ms cold node-spawn + SDK-import on first agent message.

agent_sidecar.rs connection-or-spawn branch · new agent-sidecar/src/daemon.ts entry.
Perf / SecL
28

packetade doctor CLI + diagnostics bundle

A bundled small binary that prints: Node version + path, sidecar dist hash, Tauri runtime version, AppData paths, sidecar reachable Y/N, CLI versions, known_hosts entry count, keyring service names. Plus a "Diagnostics → Export bundle" UI action zipping logs + crash reports + redacted server list.

New src-tauri/src/bin/doctor.rs with [[bin]] entry · UI surface in Tools → About · pairs with existing crashes.rs.
Perf / SecM
29

Sidecar sandboxing (sandbox-exec / bwrap)

Wrap the node sidecar in OS-level sandbox: macOS sandbox-exec, Linux bwrap / seccomp. Deny everything except the project path, ~/.claude/, ~/.codex/, and outbound HTTPS. Mitigates malicious MCP servers and prompt-injected tool calls.

agent_sidecar.rs::spawn_* paths · new core/sandbox.rs. Windows AppContainer is a stretch goal.
Perf / SecL
30

Tracing log redaction + keyring segmentation

A tracing Layer that scrubs /api[-_]?key|password|token|secret|authorization/i before the file appender. Plus split KEYRING_SERVICE into per-provider, per-tenant names so one leak doesn't blast-radius.

lib.rs::init_tracing adds RedactLayer · commands/api_keys.rs + commands/ssh_keys.rs service-name refactor.
Perf / SecS

If you only do four things — three wedges

  • Platform readiness wedge: 16 Plugin SDK · 24 Integration test harness · 26 W3C traceparent · 20 Lifecycle hooks. Everything else gets easier once these land.
  • Data-integrity wedge: 21 Schema versioning · 22 Crash-safe writes · 23 DTO contract tests. Prevents future silent-drop bugs like the v0.6.0 serverId round-trip miss.
  • Next security pass: 29 Sidecar sandboxing · 30 Log redaction + keyring segmentation. The coherent follow-on to the SSH hardening already shipped.
