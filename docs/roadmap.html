Honest status labels.

Where PacketADE actually stands, pulled straight from ROADMAP.md and backlog.md, last reconciled 2026-08-06 against v0.10.3. PacketADE wraps PTY coding CLIs — Claude Code, Codex CLI, OpenCode, PacketCode, and plain shells — plus seven API-key chat providers into one local-first desktop ADE. Most tracks below are source complete: the code is merged and locally tested, and what remains is packaged or live-environment proof. The present bottleneck is proof and distribution, not another broad source-feature wave — and two things are genuinely blocked or paused, and we say so.

What "Remote Agents v1" will mean, when it unpauses

Sign into a Packet account from a PWA, trust a desktop host, see your configured providers/models/profiles, start or continue API-agent conversations, stream events, approve or deny permission and edit prompts, and get push notifications when an agent needs attention. Provider secrets, MCP servers, files, shells, and execution never leave the desktop — there is no generic remote bridge and no raw PTY control in scope. End-to-end encryption is a hard gate before any external beta.

About those unsigned builds

Recent trust work (SSH host-key pinning, remote file-tool confinement) hardened the runtime connection path — it does not touch binary distribution. Every current artifact is unsigned: expect a SmartScreen warning on Windows and the Gatekeeper workaround on macOS. Signing and the auto-updater stay blocked until Windows + macOS code-signing certificates are acquired; that is an external dependency, not a code gap. Verify downloads against the SHA-256 hashes published with each release.

How we got here

The Flight Deck worktree-attempt runtime, Reviewer Gate, cooperative Flight graphs, Coordination Inbox, bounded autonomy, PacketCode source integration, workspace panes, Issues, GitHub + Gitea/Forgejo hosts, project Memory, dictation, enforced budget guardrails, API-agent conversations on sidecar protocol v11, PacketADE-as-MCP-server, MCP over SSH, and Codex-over-SSH are all shipped. Full notes per version live in CHANGELOG.md. One honest note: the autonomous "Planner v1" that headlined v0.7.0 was deliberately removed in July 2026 — today's Flight planning is a smaller, explicit conversation-backed step where the user applies the plan and launches attempts.

This page is a summary, and the product used to have a different name.

PacketADE was previously named PacketCode; it was renamed in mid-2026 so that name could go to the companion TUI product, and older release notes reflect the old branding (and the old "Mission" terminology for what are now Flights). The full open-work ledger is backlog.md; the short direction document this page mirrors is ROADMAP.md. Dates aren't promises — things ship when their gates clear.
