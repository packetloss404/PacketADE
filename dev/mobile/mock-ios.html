What you'd get for real in native that this mock can't show

  • True Taptic Engine haptics — subtle thump on bubble send, success thud on permission Allow, lighter tick when scrolling between sheet detents.
  • Edge-swipe back gesture — drag from the left edge to pop the chat view, with the previous screen visibly pulling in from the left.
  • Native sheet rubber-band physics — over-pull at the top, snap between medium and large detents, dismiss with a flick.
  • Native context menus — long-press a list row → preview pops up with Pin / Archive / Delete actions.
  • Swipe actions on rows — swipe-left to reveal Archive; swipe-right for Pin.
  • Spotlight + Siri integration — "Hey Siri, open my SSH hardening conversation".
  • Lock-screen and Dynamic Island live activity — "Claude is running tools…" persistent indicator with progress.
  • Real APNs — millisecond-class wake on permission requests, even from a fully-killed app state.
  • Keychain + Face ID gate — biometric unlock before showing pending approval details.
  • App switcher polish — branded preview card, not a generic Safari snapshot.

What this would cost

  • $99/yr Apple Developer Program — enrollment is the gate.
  • TestFlight distribution — internal testing (up to 100 testers) needs zero Apple review; external testing (10k testers) needs one-time per-build-family beta review (hours, not days).
  • 90-day TestFlight expiration — must re-upload before then.
  • ~2 weeks SwiftUI build — same architecture and protocol as PWA. Only client implementation differs.
