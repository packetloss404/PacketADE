4 · Pairing QR encodes {relay URL, sessionId, devicePubkey, expiry}. Fingerprint shown out-of-band for verification. Mirrors the SSH host-key pin UX from v0.6.0.

Design choices

  • Type — SF Pro Display via -apple-system stack. Identical to native on iOS.
  • Color — dark base (#0d1117) with Anthropic-warm copper accent (#d97757) and warm off-white text (#ece6dd). Borrows Claude's palette while staying compatible with PacketADE's existing Graphite tokens.
  • Bubbles — user on right with soft accent tint; assistant on left with elevated dark card. 14 px border radius, 12–13 px padding, generous line height for legibility on mobile.
  • Tool cards — left-accent border, monospace, dimmed text. Inline between turns. Tappable in the real build to expand the result.
  • Bottom sheet — backdrop dim + blur, top-rounded card sliding up. In the real build, Vaul gives this native iOS rubber-band physics.
  • Status bar — translucent, content bleeds under the Dynamic Island.
  • Tab bar — three primary destinations only: Chats, Approvals (cross-conversation rollup), Settings. Matches Claude's mobile pattern.
  • Header context badges — `82% ctx` pill is the equivalent of the desktop's SessionHealthBar — context % + cost + branch in one strip.
  • QR pairing — desktop generates Ed25519 keypair on demand, encodes pubkey + relay URL + expiry into QR. Fingerprint shown both sides for verify-out-of-band, mirroring ssh_pin_host.
