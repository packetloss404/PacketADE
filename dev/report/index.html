Executive Readout

Promising ADE alpha, not ready for broad rollout

FlightDeck has a strong product thesis, real provider-agnostic agent support, and better-than-average session recovery. The biggest gaps are control-plane gaps: orchestration ownership, PTY lifecycle integrity, approval wiring, git safety, and persistence consistency.

  • Build passed, Rust tests passed, lint failed.
  • The product direction survived review; the current runtime ownership model did not.
  • The best next move is consolidation and hardening, not a strategic reset.

Top Takeaways

High risk Strong consensus
  • Make Rust core the canonical scheduler.
  • Bind PTY stop/start semantics to task and flight state transitions.
  • Rebuild git actions around review and operator safeguards.
  • Expose dependencies, validation criteria, and review packets in the product UX.

What the room agreed on

  • The product direction is strong.
  • The current ownership split between desktop and backend is the root systems issue.
  • Planning and review UX need to catch up to the richness of the domain model.
  • Safety and trust signals need to be first-class if the product is going to supervise autonomous coding agents.
Prioritized Plan

Roadmap

P0 - Control Plane

  • Canonicalize orchestration in Rust core.
  • Make PTY lifecycle atomic with task and flight state.
  • Wire approval-needed into canonical runtime state.
  • Rebuild git actions around review and safeguards.
  • Add tests for orchestration, persistence, and PTY lifecycle.

P1 - Product Fit

  • Expose dependencies and milestone validation in the UI.
  • Make launch prompts, repo context, and session ownership auditable.
  • Add review packets with files changed, tests, cost, and outcomes.
  • Make repo and branch context first-class per flight.

P2 - Scale And Maintainability

  • Split large files like TerminalPane and the TUI app controller.
  • Normalize TS/Rust contracts and shrink handwritten DTO mapping.
  • Improve transcript retention, event fan-in, and hidden-view performance.
  • Lay groundwork for collaboration and richer review records.
