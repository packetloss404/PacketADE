## B-VOICE-001 — Desktop-wide voice workflow

Status: backlog

Priority: low

Reason:

- BridgeMind has a dedicated voice product and PacketCode does not
- PacketCode currently only has limited browser speech recognition inside `InsightsView`
- a partial response would likely create product noise rather than product value

Current decision:

- do not actively build voice right now
- revisit only if PacketCode is ready to build a real desktop-wide workflow

Minimum bar for reconsideration:

- push-to-talk or toggle recording
- reusable voice input across the app
- transcript history
- clear privacy model
- practical workflows like prompt dictation, review notes, commit text, and issue updates
